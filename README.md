# IBM 6500 M08 Reflection — Han Mai

[View presentation](https://hanamai111.github.io/ibm6500-m08-gtsummary-reflection/)

Open M08.Rproj, then the QMD. Quarto revealjs; R dependencies: gtsummary, dplyr, gt, broom, broom.helpers, sandwich, lmtest.

The HTML contains aggregate coursework outputs only. Restricted CEP call records are deliberately excluded. Set CEP_CALLS_CSV to an authorized local calls_UI_analysis.csv before rendering. No simulated respondents are used. The consumer survey was not yet collected.

Analysis is exploratory: recorded calls are not unique callers, qualified inquiries, or patients. See the presentation for assumption checks and limitations.
